# 手持多帧超分：经典管线的技术实现（与 JSR 同图对比）

> 写给 Jiangtherapee SR (JSR) 作者。我们是一条**零训练的经典计算管线**（相位相关对齐 + SR 网格直接融合），
> 与 JSR 这类学习方案思路完全不同，把实现要点和验证数据整理如下，欢迎交流拍砖。
> 作者 GitHub 看到这份文档的话：所有代码在 `sr_process.py`（约 600 行，纯 numpy/opencv/rawpy）。

## 一、管线总览

```
RAW 连拍 → 中心裁切半尺寸相位相关(粗对齐) → 全分辨率残差精修 → 帧筛选
       → 帧间光度增益/偏置校正 → SR 网格直接融合(分块鲁棒加权) → gamma/色阶/锐化 → 16bit TIFF + JPG
```

与旧版（对齐回参考帧网格 → 统一插值放大 → 加权平均）的本质区别在最后一步：
**每帧按含小数部分的位移直接 remap 到超分网格**，各帧采样落在 SR 网格的不同亚相位上。
旧版先插值回参考帧网格，亚像素相位在那一半就被抹掉了，融合只剩降噪。

## 二、关键实现

### 1. 对齐：半尺寸粗估 + 全分辨率残差精修

半尺寸（half_size demosaic）相位相关快且稳，但精度只有 ~0.1-0.2px，×2 映射后误差翻倍。
做法：整数部分预平移取窗 → 全分辨率相位相关补残差。合成数据实测精修后中位误差 **0.040px**。

```python
def _refine_shift(ref_gray, frame_gray, d, crop_ratio=0.5):
    ix, iy = int(round(d[0])), int(round(d[1]))
    # 中心 50% 窗, 按整数部分平移取同一场景
    (rx, ry), _ = cv2.phaseCorrelate(ref_c * win, frm_c * win)
    return (ix + rx, iy + ry)   # 残差补偿
```

### 1b. 帧间旋转：ECC 欧氏精修（v2.1 新增）

真实手持连拍帧间除平移外还有 **0.1~0.25° 的旋转**（实测 DSC_1677 达 −0.245°），
在 8288px 宽度上意味着边缘近 15px 错位——纯平移模型必然出重影伪影。
解法：半尺寸 ECC（MOTION_EUCLIDEAN，整数平移预取窗）估出每帧的旋转+残余平移，
换算成全尺寸仿射，融合 remap 从 `s + d` 升级为逐帧仿射采样：

```python
E, fx0, fy0, x0h, y0h = _refine_euclidean(ref_half, fg_half, dx, dy)  # 60 次迭代 ~1s/帧
Mh = Th(fx0,fy0) @ E3 @ To(-x0h,-y0h)      # 半尺寸仿射
A_full = S2 @ Mh @ inv(S2)                  # 换算全尺寸 (S2=diag(2,2,1))
mx = A[0,0]*SX + A[0,1]*SY + A[0,2]         # 融合 remap
```

画布同时按旋转角内切收缩（θ·h/2, θ·w/2）。实测该修复使输出噪声（中值残差）
从 2.52 降至 1.75，鬼影消失，与 JSR 同区域对比从落后转为持平。

### 2. 帧间光度校正

连拍曝光/增益漂移会让平均出现色鬼影。对**大模糊（σ=8）后的灰度**做鲁棒最小二乘
（先模糊是关键——残余错位几像素不会破坏低频光度关系），每帧估 `frame ≈ g·ref + b`，
截断 g∈[0.9,1.1]、b∈±0.05 后在融合前校正。

### 3. SR 网格直接融合（核心）

```python
# SR 像素 U 的场景坐标（参考帧像素单位）
s = (U + 0.5)/scale - 0.5 + crop_x0
# 每帧按含小数部分的位移直接采样（remap, INTER_CUBIC）
S[i] = cv2.remap(frame_i, s + d_i, ...)   # d_i = 第 i 帧相对参考帧的位移
```

- 帧缓存用 **uint16**（45MP 一帧 float32 540MB，16 帧 float32 装不下）
- **分块处理**（tile=1024）：每块把 n 帧样本堆叠成 (n, th, tw, 3)，
  避免全尺寸 float64 累加器的 2GB+ 开销

### 4. 鲁棒加权（去鬼影）

以逐像素**中位数**为锚（16 帧里少数帧上的运动物体被自动拒斥）：

```python
med = np.median(S, axis=0)
rel = np.abs(S - med).mean(axis=3) / (1310.0 + med.mean(axis=2))   # 相对偏差, 1310≈0.02×65535 防 0 除
w  = 1.0 / (1.0 + (rel / 0.25) ** 2)                                # 平滑 Huber
out = (S * w[...,None]).sum(0) / w.sum(0)
```

### 5. 重叠画布

场景点 s 需对每帧满足 `s + d_i ∈ [0, w)`，画布取正确交集
`[max(0, −min_dx), w − max_dx]`（旧版公式在位移不对称时会算错边界）。

## 三、验证数据

### 合成数据（有真值）

σ=0.4 带限散斑场景（LR 帧真正欠采样），16 帧、±6px 亚像素位移、σ=8 噪声、±1.5% 增益漂移。
直接对融合输出（线性域）评分，参考图按同一采样网格从真值构造：

| 候选 | PSNR | 梯度相关 |
|---|---|---|
| 单帧 bicubic 2x | 28.99 dB | 0.460 |
| 旧算法（对齐回参考帧再放大） | 29.27 dB | 0.478 |
| **新算法（自估位移）** | **29.67 dB** | **0.528** |
| 新算法 + 真值位移 | 29.64 dB | 0.520 |

自估位移 ≈ 真值位移，对齐不是瓶颈；提升上限受限于"插值+平均"只能部分消除混叠。

### 真实照片（7 组连拍，24MP/45MP）

锐度（拉普拉斯方差）新算法在高分辨率高噪声组达到旧算法 3-5 倍且噪声更低；
低噪声组持平。

## 四、坦诚的差距与下一步

JSR 的优势我们短期内不会追：训练先验带来的真细节恢复、全流程线性度标定
（阶梯环响应贴 y=x 这点非常扎实）、单应矩阵对齐（NEWHOMOG，我们只做全局平移）、
wgpu GPU 推理速度。我们管线的相对优势：零训练/零模型文件、可解释、内存可控、
任意倍率、对 RAW/JPG/TIFF 通吃。

下一步按预期收益排序：
1. 正则化反演 / 核回归融合（把"插值+平均"换成带图像先验的求逆，合成数据显示还有数 dB 空间）
2. 分块或单应对齐，处理景深视差与大气抖动
3. RAW 域（Bayer）超分
