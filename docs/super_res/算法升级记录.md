# 算法升级记录：SR 网格直接融合（v2）

**日期**：2026-09-05
**改动**：`sr_process.py` 的 `reconstruct()` 重写为 v2；旧实现保留为 `reconstruct_legacy()`（CLI `--legacy` 可调用）。

---

## 一、为什么要重写

对 7 组真实连拍（test4-10，含 24MP/45MP）的实测证明：旧算法（先把每帧对齐回参考帧网格、再统一双三次放大、加权平均）的输出**只比单帧降噪，不比单帧多细节**，细部纹理反而略柔。

根本原因：每帧先用 `warpAffine` 插值到参考帧网格——这一步把该帧特有的亚像素采样相位抹掉了；之后所有帧又落在同一张超分网格上。融合因此退化为"降噪平均"。

## 二、新算法设计（`reconstruct()` v2）

1. **帧缓存 uint16**：45MP 一帧 float32 要 540MB，16 帧装不下；uint16 减半（~270MB），总共约 4.3GB。
2. **全分辨率位移精修**（`_refine_shift`）：半尺寸相位相关精度 ~0.1-0.2px（×2 映射到全分辨率会放大），按整数部分预平移取窗后再做一次全分辨率相位相关，把残差补回来。合成数据实测：精修后中位误差 **0.040px**。
3. **光度校正**（`_estimate_gain_bias`）：连拍的曝光/增益漂移会让平均产生色鬼影。对大模糊（σ=8）后的灰度做鲁棒线性拟合（抗错位干扰），融合前校正每帧增益/偏置。
4. **SR 网格直接融合**：超分像素 U 的场景坐标 `s = (U+0.5)/scale − 0.5 + crop`，每帧按 `s + d_i`（含小数部分）直接 `cv2.remap` 到超分网格——各帧采样落在网格的**不同亚相位**上，这是超分增益的来源。
5. **分块鲁棒融合**（tile=1024）：以逐像素中位数为锚，`w = 1/(1+(rel/0.25)²)` 压低离群帧（运动/鬼影），替代旧版的高斯掩码；`--no-deghost` 退化为平均。
6. **重叠画布修正**：旧版公式在位移不对称时算错边界；v2 按正确交集 `s ∈ [max(0,−min_dx), w−max_dx]` 计算。

## 三、合成数据验证（有真值）

场景：σ=0.4 高斯带限散斑 + 结构（LR 帧真正欠采样），16 帧、±6px 整数+低 discrepancy 亚像素位移、σ=8 噪声、±1.5% 增益漂移。**直接对融合输出（线性域）评分**，参考图按工具同一采样网格从真值构造，无任何后处理混淆。

| 候选 | PSNR | 梯度相关 |
|---|---|---|
| 单帧（bicubic 2x） | 28.99 dB | 0.460 |
| 旧算法 | 29.27 dB | 0.478 |
| **新算法（自估位移）** | **29.67 dB** | **0.528** |
| 新算法 + 真值位移 | 29.64 dB | 0.520 |

结论：
- 新算法 > 旧算法 > 单帧，且**自估位移 ≈ 真值位移**（对齐管线到位）。
- 视觉上单帧的颗粒被抹成团，新算法恢复出接近真值的细颗粒。
- 提升幅度受限于此融合方式的本质：`插值 + 平均` 只能部分消除混叠，不能完全反演欠采样算子。要更进一步需要正则化反演 / 核回归（README"已规划改进"）。

**测试设计的重要教训**：第一版合成场景用了 σ=1.1 的模糊——MTF 在 LR 奈奎斯特处仅 0.3%，场景里根本没有超出单帧带宽的信息，任何算法都不可能超分（实测三个候选全部打平）。合成 SR 测试必须让 LR 帧真正欠采样。

## 四、真实照片验证（7 组）

输出：`D:\photo\JPG\test\output\<set>_v2.tif`（+jpg），对比图 `output\对比\<set>_三方对比.png`，指标 `output\对比\三方指标.txt`。

锐度（拉普拉斯方差，同区域同尺度）与噪声（中值残差 std，0-255 尺度）：

| 组 | 用帧(新/旧) | 锐度 单→旧→新 | 噪声 单→旧→新 |
|---|---|---|---|
| test4 (24MP) | 13/13 | 10 → 3 → 3 | 0.7 → 0.3 → 0.2 |
| test5 (45MP) | 16/16 | 30 → 21 → 14 | 1.2 → 0.9 → 0.7 |
| test6 (24MP) | 16/16 | 29 → 13 → 16 | 1.2 → 0.6 → 0.9 |
| test7 (24MP) | 7/7 | 25 → 15 → 12 | 1.0 → 0.6 → 0.6 |
| test8 (JPG) | 13/13 | 12 → 5 → 3 | 0.7 → 0.3 → 0.2 |
| test9 (45MP) | 16/16 | 51 → 9 → 26 | 1.6 → 0.6 → 0.9 |
| test10 (45MP) | 8/12 | 95 → 9 → 39 | 2.1 → 0.7 → 1.2 |

（锐度/噪声为每区域均值，详见三方指标.txt）

结论：
- **高分辨率高噪声组（test9/10，Z7 45MP）新算法大胜**：锐度达到旧算法 3-5 倍、噪声仍更低；肉眼看脚手架/窗框/瓦片纹理明显更清晰（旧算法发糊）。
- **低噪声组（test4/5/6/7/8）大致持平**：锐度略低或持平，噪声更低——净收益为正但幅度小。原因：这些素材本身噪声低、位移小，可恢复的高频信息少。
- test10 v2 用默认 max_shift=50 只保留 8/17 帧（旧实验用 100 保留 12 帧）；小位移集的相位多样性有限。
