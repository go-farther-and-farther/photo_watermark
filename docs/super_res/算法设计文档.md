# 手持多帧超分辨率合成工具 — 算法设计文档

## 1. 概述

将一组手持连拍 RAW 文件合成为一张 2x（或更高倍率）超分辨率图像。

**输入**: N 张连拍 RAW（推荐 16-25 张）
**输出**: 16-bit TIFF + JPG

## 2. 算法流水线

```
RAW 连拍 (N张)
    │
    ▼
┌─────────────────────────────────────────────┐
│ 阶段1: 中心裁切 + 相位相关对齐                │
│   读取每张 RAW → 解拜尔 → 灰度图              │
│   加 gamma 校正（线性RAW太暗）                 │
│   中心裁切 60%（避免边缘干扰）                 │
│   相位相关法估计亚像素位移                     │
│   输出: 每帧的 (dx, dy) 平移量                │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│ 阶段2: 帧筛选                                │
│   过滤位移过大的帧（对齐不准）                  │
│   从剩余帧中选亚像素分布最均匀的 M 帧          │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│ 阶段3: 超分辨率重建                          │
│   计算所有帧对齐后的重叠区域                   │
│   逐帧: 读取全分辨率 RGB                      │
│        平移对齐到参考帧                       │
│        裁切到重叠区域                         │
│        上采样到 2x 网格                       │
│        去鬼影加权                             │
│        累加到超分网格                         │
│   归一化得到超分辨率图像                       │
└─────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────┐
│ 阶段4: 后处理                                │
│   sRGB gamma 校正                            │
│   自动亮度拉伸（去 0.5% 极值）                 │
│   锐化 (Unsharp Mask)                        │
│   输出 16-bit TIFF + JPG                     │
└─────────────────────────────────────────────┘
```

## 3. 各阶段详解

### 3.1 RAW 解拜尔

使用 rawpy (LibRaw) 进行 AHD 解拜尔：

```
RAW Bayer 阵列 → 16-bit 线性 RGB
参数:
  - demosaic: AHD (自适应同质性导向)
  - white balance: 使用相机白平衡
  - gamma: (1,1) 线性输出，不应用 gamma
  - output_bps: 16
  - color_space: sRGB
```

输出是 float32 [0,1] 的线性 RGB 图像。

### 3.2 帧间对齐

**为什么用相位相关而不是特征匹配？**

| 方法 | 精度 | 速度 | 鲁棒性 |
|------|------|------|--------|
| ORB + 单应性 | 1-2px | 慢 | 对暗图失败 |
| 相位相关 | 0.01px | 快 | 需要中心裁切 |

实测 ORB 在线性 RAW（很暗）上全部失败，相位相关在中心裁切后非常稳定。

**对齐流程:**

```python
# 1. 读取灰度图 + gamma 校正
gray = cv2.cvtColor(rgb, COLOR_RGB2GRAY)
gray = np.power(gray, 1/2.2)  # 线性RAW太暗，加gamma让细节可见

# 2. 中心裁切 60%（避免边缘黑边/畸变干扰）
h, w = gray.shape
ch, cw = int(h * 0.6), int(w * 0.6)
crop = gray[(h-ch)//2:(h+ch)//2, (w-cw)//2:(w+cw)//2]

# 3. 相位相关估计亚像素位移
win = cv2.createHanningWindow((cw, ch), CV_32F)
shift, response = cv2.phaseCorrelate(ref_crop * win, tgt_crop * win)
dx, dy = shift  # 亚像素精度，约 0.01 像素
```

**相位相关原理:**

```
两帧图像的互功率谱:
              F₁(u,v) · F₂*(u,v)
S(u,v) = ─────────────────────────
           |F₁(u,v) · F₂*(u,v)|

S(u,v) 的逆FFT是一个脉冲，脉冲位置 = 位移量
亚像素精度通过抛物线插值峰值位置实现
```

**为什么中心裁切？**

手持拍摄时，画面边缘的位移比中心大（旋转+透视效应）。裁切到中心 60% 后：
- 边缘干扰消除
- 位移接近纯平移，相位相关准确
- 位移量减小，更容易估计

### 3.3 帧筛选

不是所有帧都适合超分：

```
位移太大 (>100px) → 对齐可能不准，产生重影
位移太小 (<0.1px) → 没有新的亚像素信息
位移刚好 (0.1~100px) → 有亚像素多样性，适合超分
```

**筛选策略:**

1. 按位移距离过滤: `dist = sqrt(dx² + dy²) > max_shift` 的帧丢弃
2. 从剩余帧中贪心选择亚像素分布最均匀的 M 帧:
   - 每次选一帧，使其与已选帧的位移距离最大化
   - 保证亚像素位置覆盖均匀

### 3.4 超分辨率重建

**核心思想:** 多帧的亚像素位移相当于在高分辨率网格上不同位置采样。

```
原始像素网格 (2x2):     超分网格 (4x4):
┌───┬───┐               ┌─┬─┬─┬─┐
│ A │ B │               │ │ │ │ │ ← 第1帧采样位置
├───┼───┤               ├─┼─┼─┼─┤
│ C │ D │               │ │ │ │ │ ← 第2帧采样位置(偏移0.5px)
└───┘───┘               ├─┼─┼─┼─┤
                        │ │ │ │ │ ← 第3帧采样位置(偏移0.3px)
                        ├─┼─┼─┼─┤
                        │ │ │ │ │ ← 第4帧采样位置(偏移0.7px)
                        └─┴─┴─┴─┘
```

**步骤:**

```python
# 1. 计算重叠区域
#    所有帧对齐后的有效区域交集
#    避免边缘出现黑边

# 2. 对齐 + 裁切
for each frame:
    # 平移对齐到参考帧坐标系
    aligned = align_frame(ref, frame, dx, dy)
    # 裁切到重叠区域
    cropped = aligned[y0:y1, x0:x1]

# 3. 上采样到超分网格
sr_frame = cv2.resize(cropped, (2*w, 2*h), INTER_CUBIC)

# 4. 去鬼影加权
#    与参考帧比较差异
#    静止区域: 高权重 (利用多帧降噪+超分)
#    运动区域: 低权重 (只用参考帧，避免鬼影)

# 5. 加权累加
sr_sum += sr_frame * weight
sr_weight += weight

# 6. 归一化
sr_result = sr_sum / sr_weight
```

### 3.5 去鬼影

场景中的移动物体会在不同帧中出现在不同位置，直接融合会产生鬼影。

```
参考帧:    人在这里
第3帧:     人移到那里了 ← 直接融合会出重影

解决方案:
1. 计算每帧与参考帧的差异图
2. 差异大的区域 = 运动区域
3. 运动区域降低该帧权重，倾向参考帧
```

```python
# 差异检测
diff = mean(abs(aligned_frame - reference_frame), axis=2)
motion = diff > threshold  # 阈值化

# 形态学平滑
motion = morphology_close(motion)
motion = morphology_open(motion)

# 高斯模糊生成软边缘掩码
weight = 1 - GaussianBlur(motion, 0.8)
```

### 3.6 后处理

**sRGB gamma 校正:**

RAW 解拜尔后是线性图像（gamma=1），需要转换到 sRGB 才能正确显示：

```
sRGB = linear ^ (1/2.2)
```

**自动亮度拉伸:**

```python
# 对每个通道，去掉最暗和最亮的 0.5%，拉伸到 0-1
for c in range(3):
    lo = percentile(channel, 0.5)
    hi = percentile(channel, 99.5)
    channel = clip((channel - lo) / (hi - lo), 0, 1)
```

**锐化 (Unsharp Mask):**

```
sharpened = image + strength * (image - GaussianBlur(image))
```

## 4. 内存优化

24MP 图像 × 16帧 × float32 × 3通道 = 约 4.4GB，内存压力大。

**优化策略:**

| 策略 | 效果 |
|------|------|
| 对齐用半尺寸灰度图 | 内存和速度都优化 |
| 逐帧读取，用完释放 | 峰值只占 1 帧内存 |
| 重叠区域裁切 | 超分网格更小 |
| gc.collect() 强制回收 | 及时释放大数组 |

## 5. 与 JSR 的对比

| 方面 | JSR | 本工具 |
|------|-----|--------|
| 对齐 | 未知（可能是光流） | 相位相关 + 中心裁切 |
| 大位移处理 | 未知 | 能处理 100px+ |
| 暗图对齐 | 未知 | gamma 校正后稳定 |
| 色彩 | 偏色严重 | 保持原始色彩 |
| 输出 | 16-bit TIFF | TIFF + JPG |
| 开源 | 否 | 是 |

## 6. 限制与改进方向

### 当前限制

1. **只支持平移**: 假设帧间只有平移，没有旋转和透视变化
2. **全局对齐**: 假设整个画面位移一致，有深度变化时不准
3. **去鬼影简单**: 只用全局差异检测，无法处理局部运动

### 改进方向

1. **光流对齐**: 用 RAFT/GMFlow 做稠密光流，精度更高
2. **分块对齐**: 把图像分块，每块独立对齐，处理非平面场景
3. **深度学习**: 用神经网络做超分重建（Real-ESRGAN 等）
4. **RAW 域处理**: 不解拜尔直接在 Bayer 域做超分，保留更多信息

## 7. 使用建议

### 拍摄技巧

| 要求 | 说明 |
|------|------|
| 连拍数量 | 16-25 张 |
| 连拍速度 | 越快越好（30fps+ 最佳） |
| 手持方式 | 靠栏杆/墙壁稳定，但不要完全固定 |
| 构图 | 尽量保持相同构图，靠手的自然抖动 |

### 命令行参数

```bash
python sr_process.py \
  --input ./raw_burst/ \       # RAW 文件夹
  --output result.tif \         # 输出路径（自动同时输出 JPG）
  --scale 2 \                   # 超分倍率
  --max-frames 16 \             # 最大使用帧数
  --max-shift 100 \             # 最大允许位移(像素)
  --sharpen 0.3 \               # 锐化强度
  --denoise                     # 启用降噪
```
