## 一、项目现状一句话

`photo_watermark.exe`（**v2.1.0**，93MB，单一全量版）＝ 水印 + EXIF 查看 + 超分 +
**调色模板**。超分侧两条路：通用手持连拍管线（对齐/选帧/融合/去卷积）和
**暗背景亮小主体 ROI 堆栈**（月亮/行星，自动识别，产出裁到主体的母版）；

`photo_watermark.exe` 同步成同一份。根目录被运行中的程序占用时会跳过同步并提示。

## 二、当前管线架构（sr_process.py，~1500 行）

```
RAW/JPG 文件清单（GUI 直传，无临时拷贝）
  ├─ 预对齐：相位相关（半尺寸）→ 参考帧 + 全帧位移 + 各帧锐度得分   [计时] 预对齐
  ├─ 选帧：锐度门控（得分<组内最佳×0.35 剔糊片，保底6帧，--no-sharp-gate）
  │         → 位移≤自适应上限（画面最大边8%，保底150px）
  │         → 亚像素均匀取 top-k（GUI 默认 12）
  ├─ reconstruct()：
  │   ├─ 读帧缓存（uint16）                                 [计时] 读帧
  │   ├─ 逐帧精修：全分辨率相位相关 → ECC 欧氏 → ECC 单应
  │   │    （解析门控+残差验收双保险，不达标退欧氏）          [计时] 精修
  │   │   每帧：增益/偏置光度校正、运动占比、模糊RMS
  │   ├─ 剔除：运动占比>15% 整帧剔；模糊RMS>中位×1.2 整帧剔
  │   ├─ 局部对齐：128px(半)分块相位相关残差场，验收制采纳    [计时] 局部对齐
  │   ├─ 噪声感知加权：w=1/(rms²+floor)，截断[0.5,2]，参考帧取中位
  │   └─ 融合：2x 网格逐像素射影 remap + 中位数锚定 Cauchy   [计时] 融合
  │       （块间 ThreadPoolExecutor 并行，上限8 worker，
  │         并行期间 cv2.setNumThreads(1) 防超订，结果逐位一致）
  └─ 输出：Linear DNG 底片（Adobe结构）+ JPG（色度降噪→RL反卷积
      锐化(比率上限4.0)→gamma2.2→亮度单增益拉伸→高光去色→色度降噪）
```

K14 外挂引擎（可选勾选）：**Fast K14 后端硬性要求恰好 14 帧**，不足自动回退内置
管线；>14 帧的组取最锐 14 帧交引擎，输出 DNG 读回需 `imagecodecs._jpeg8`（打包
必带）。输出同样走 EXIF 继承 + 预览渲染。

**小主体 ROI 路径（2026-10-17 晚追加）**：当参考帧呈"暗背景 + 亮小目标"
（面积占比<6%、对比度>15×、圆度>0.55、全帧 P90<峰值×0.1）时，`process()` 在选帧后
切到 `process_subject_roi()`（月亮/行星/日面）：逐帧以主体为中心裁 ROI → 平移+旋转
亚像素配准 → 主体内光度归一 → lucky 选帧 → 2x 融合 → PSF 实测去卷积 → 主体中位定标。
输出是**裁到主体的 ROI 母版**，不再是 99.6% 黑的全帧巨幅。`--no-subject-roi` 可关。
设计与实测见《月亮主体ROI堆栈-设计-2026-10-17.md》。

## 四、关键坑（新会话必读）

1. **打包**：spec 的 excludes 不能含 numpy/cv2（超分依赖）；imagecodecs 顶层是
   懒加载映射，必须 hiddenimports=['imagecodecs', 'imagecodecs._jpeg8']，否则运行时
   `could not import name 'jpeg8_decode'`。改动后 `PyInstaller photo_watermark.spec -y`
   重打，根目录与 dist 同步覆盖。构建验证三件套：warn 文件无缺失、
   Analysis-00.toc 含 sr_gui/sr_process/_jpeg8、启动存活冒烟。
2. **测量方法**：A/B 两版输出的 PSD 对比必须**共用同一组分析窗**（各挑各的窗会
   得出完全相反的结论，实测吃过亏）；局部对齐生效后内容偏移随空间变化，区域级
   常数偏移失效，需逐窗配准（粗搜±80px+相位精修）。sr_ab_psd.py 目前是区域级，
   用于局部对齐后的 A/B 会失准。
3. **坐标系**：画布原点 (crop_x0, crop_y0) 在 ref 帧坐标里；SR 画布坐标 ≠ 原始帧
   坐标（实测错配导致诊断 NaN）；透视/局部场余量让每版画布原点不同，跨版对比
   必须先 phaseCorrelate 实测偏移。
4. **float64 提升**：`float32 数组 - int32 数组` 会升 float64，cv2.remap 拒收
   （_apply_field 踩过，已修+类型断言）。
5. **GUI 测试**：devtests/sr_ui_smoke.py 走真实主窗口点超分按钮；给 SR 窗口截图
   不要用主程序入口（用户会看到窗口乱闪/误点），直接 `sr_gui.App(root)` 构建
   单窗口 + PIL ImageGrab。
6. **venv**：`.venv` 缺 rawpy/pytest；用系统
   `C:/Users/LQL/AppData/Local/Programs/Python/Python312/python.exe`（全依赖）。
