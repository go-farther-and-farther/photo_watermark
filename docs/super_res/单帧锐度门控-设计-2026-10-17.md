# 单帧锐度门控（糊片自动剔除）— 设计 — 2026-10-17

## 一、动机

防抖 A/B 实测（2026-10-17，Z6+85mm f/5.6，1/15s 手持 46 帧，见
`C:\Users\LQL\Pictures\raw\100NCZ_6\防抖测试结果_200-245\`）暴露了现管线的两个盲区：

1. **选帧阶段不看单张锐度**：`select_best_frames` 只滤大位移帧（位移过滤 +
   亚像素均匀选帧），糊帧只要位移不大就照常进入重建；
2. **重建期的模糊 RMS 门限是相对中位数×1.2**：整批糊片会把中位数抬高、糊片
   全部豁免；且它以参考帧为基准——参考帧自己糊，所有帧的残差 RMS 都失真。

实测组内单帧锐度（LapVar2x）差异可达 **30 倍**（1461 vs 52913），逐帧无参考
即可判定。防抖测试用的指标经过真机验证：同组开关防抖 4~5.6 倍差、对焦失误
帧/体晃帧与锐帧分离清晰。

## 二、指标：半尺寸灰度上的拉普拉斯方差

```python
def sharpness_score(gray):   # 输入 = read_raw_as_gray(half_size=True)
    return float(cv2.Laplacian(gray.astype(np.float64), cv2.CV_64F, ksize=3).var())
```

- **抗噪来自解码端**：rawpy `half_size=True` 解码本身按 2×2 合并像素，噪声
  已被压掉，直接求梯度即可。设计初版在半尺寸之上又做了 2×2 降采样（等效
  1/4 分辨率），实测被否：几像素的运动模糊在 1/4 分辨率下被抹平——
  **46 帧防抖 A/B 组回代，与全分辨率真值的排序一致性 0.840 → 0.997、
  门控决策一致率 27% → 97%**（改为半尺寸直接计算后）。
- **无参考帧依赖**：单帧即可算，参考帧糊不糊不影响判定。
- **零额外解码成本**：算在 `align_all_frames` 本来就要解码的半尺寸灰度上。
- 得分绝对值只在同一解码尺度下可比；门控按组内相对比例取阈。
- 已知边界：高感+平坦画面时噪声地板抬升（相对门限下全组一起抬，
  不会误剔，最多漏剔）。

## 三、接入点与规则

选帧阶段最先执行（糊帧的相位相关位移本来就不可信，先剔再做位移过滤）：

```
select_best_frames(raw_files, shifts, ref_idx, max_frames, max_shift,
                   sharp=各帧得分, sharp_gate=True)
  锐度门控（新增，最先）
    门槛 = 组内候选帧最佳分 × 0.35
    得分 < 门槛 且非参考帧 → 剔除，逐帧打日志
    保底：剔除后剩余 < 6 帧或候选 ≤ 6 帧时不启用（保底交给下游）
  位移过滤（原有）
  亚像素均匀选帧（原有）
```

- **阈值 0.35×最佳**：VR 实测组（0200–0245，46 帧）回代——组内得分连续分布，
  被剔除端 ≤ 最佳的 33%，保留端 ≥ 39%，0.35 切在中间；更糊的帧对超分只贡献
  噪声，多剔不亏（有帧数保底兜底）。
- **绝对比例而非中位数相对**：中位数在"过半糊片"时失效——这正是要补的洞。
- **参考帧豁免 + 重选**：参考帧是全组对齐锚点，不参与剔除；但参考帧选择
  （位移中位数）可能落在糊帧上——糊参考让所有帧的残差失真（46 帧实测组
  即触发：参考帧选中 DSC_0236，得分 0.163 < 门限 0.194）。故门控开启且
  参考帧得分低于门限时，在保留帧里重选参考并重新预对齐（仅触发时多一次
  半尺寸解码）；糊参考的融合兜底仍由下游噪声加权承担。
- **保底 6 帧**：融合中位数锚定至少 4 帧才稳（sr_suggest.MIN_COMPOSE_FRAMES），
  留余量取 6；不够就整组不启用门控，交给重建期既有门限。
- 早期返回路径（n ≤ max_frames）同样过门控——GUI 常见 12~18 帧组走的
  正是这条路，原来这里连位移过滤都没有。

## 五、明确不改动

- `burst_tools.sharpness_rank`（K14 选帧）：已按高频能量取 top-14，糊片只有
  在锐帧不足 14 张时才会入选，暂不动（候选改造项）；
- `reconstruct` 的运动占比/模糊 RMS 门限：保留，作为第二道防线（它还能抓
  内容移动）；噪声加权照旧给糊帧降权；
- `sr_suggest` 分组判定：抽样 8 帧本就为快速判定，门控在正式管线里执行。
