# 照片调色模板（简单调色 + 套用模板）— 设计 — 2026-10-18

## 一、目标与非目标

**目标**：给 `photo_watermark.exe` 加一个"简单调色"能力——主界面一个下拉框选模板、
一个强度滑块，导出时自动套在照片本体上；内置几套常用观感，可另存自定义模板。

**非目标**（第一版不做）：
- 不做完整调色台（曲线、HSL、分离色调、局部调整）；
- 不接 `.cube` 文件（`_lut` 里那条是 N-Log→Rec709 的视频技术转换，输入域不匹配，
  见下）；
- 不改超分/DNG 管线（SR 模块的线性母版保持原样）；
- 不处理 RAW 解码（沿用现有的 JPEG/PNG/TIFF 读图路径）。

## 二、为什么不是直接套 `_lut` 里那个 .cube

那条 LUT 是「N-Log(Log3G10) → 线性 → look → Rec.709」的**技术转换**，
输入域是 N-Log 编码。照片是 sRGB 显示编码，直接喂进去是双重编码：
实测 sRGB 0.18 中灰会被映射到 0.050（暗 1.8 档）。

可移植的是它的 **stage-2 look**：黑点、曝光、高光肩、门控色度。本设计把这组
参数搬进线性域，并按照片自适应黑点（视频那条的固定黑点 0.012 会把照片暗部吃掉）。

## 三、色彩管线（`color_grade.py`，全部在线性光上）

输入 sRGB 8bit → `srgb_to_linear` → 以下步骤 → `linear_to_srgb` → 8bit。

1. **白平衡**：`R *= 2^(0.30·temp)`，`B *= 2^(-0.30·temp)`，`G *= 2^(0.15·tint)`
2. **曝光**：`x *= 2^ev`
3. **黑点**：`x = max(x - black, 0) / (1 - black)`（白点保持 1）
   `black = auto` 时取图像线性亮度的 P0.5（夹在 0–0.012）
4. **对比**：绕 0.18 的幂曲线 `out = 0.18 · (x/0.18)^c`（c>1 加对比，c=1 恒等；
   对 0 保持 0）
5. **高光肩**：`x > 0.75` 时 `x = 0.75 + cap·(x-0.75)/(x-0.75+q)`，`q=3`
6. **阴影提亮**：`x += s·(1-x)²`
7. **饱和**：`y = x·LUM`；`k = 1 + sat·smoothstep(chroma/GATE)`；
   `out = y + k·(x-y)`（GATE=0.06，近中性区保护，肤色/灰面不泛色）
8. 裁到 [0,1]

**强度**：参数朝恒等缩放 `p' = p_identity + t·(p - p_identity)`，t = 强度/100，
整条管线只跑一次（不做两次重采样）。

## 四、模板 = 8 个参数

| 参数 | 范围 | 恒等值 | 说明 |
|---|---|---|---|
| 曝光 | -2..+2 EV | 0 | |
| 对比 | 0.5..1.5 | 1.0 | 绕 0.18 的幂 |
| 高光 | 0..0.30 | 0 | 肩部上限，压亮部 |
| 阴影 | 0..0.05 | 0 | 线性提亮量 |
| 饱和 | 0..1.6 | 1.0 | 门控色度 |
| 色温 | -1..+1 | 0 | 正=暖 |
| 色调 | -1..+1 | 0 | 正=偏品红 |
| 黑点 | 0..0.02 或 auto | 0 | auto=按图 P0.5 |

**内置模板**（`水印设置.ini` 的 `[调色模板:名称]` 段）：

| 名称 | 参数 | 说明 |
|---|---|---|
| 原图 | — | 关闭，默认值 |
| 标准 | 对比1.10 饱和1.08 高光0.04 黑点auto | 通用小清新 |
| 视频感 | 曝光-0.15 高光0.12 饱和1.30 黑点auto | `_lut` 那条 look 的移植 |
| 清新 | 曝光+0.15 对比1.05 饱和1.10 色温-0.30 阴影0.01 | 冷调通透 |
| 暖调 | 曝光+0.05 对比1.12 饱和1.15 色温+0.35 高光0.06 | 暖调胶片 |
| 黑白 | 饱和0 对比1.15 | |

**自定义模板**：设置窗口「调色」页可拖 8 个滑块，点「另存为模板」写入
`用户设置.ini` 的 `[调色模板:名字]`；同名覆盖，可删除。读取时用户段覆盖内置段。

## 五、界面与接入点

- **主窗口**：样式区下方新增 `调色模板` 面板——模板下拉 + 强度滑块（0–100）+ 提示；
  变更即刷新预览。默认「原图」，不改变现有行为。
- **设置窗口**：新增「调色」页（模板下拉 + 8 滑块 + 另存/删除）。
- **处理位置**：`process_single_image()` 里，缩放之后、加水印之前，
  `image = apply_grade(image, template, strength)`。**只作用于照片本体**，
  边框颜色/水印/Logo 不受影响。
- **CLI**：`--grade 模板名 --grade-strength 0-100`。

## 六、存储

- `水印设置.ini`：新增 `[基础设置] 调色模板=原图 / 调色强度=100` 与 6 个
  `[调色模板:*]` 段（随包分发）。
- `用户设置.ini`：只存用户改过的项与自定义模板（沿用 `update_ini_value`）。

## 七、性能

实测（随机噪声图，numpy 链路，不含 JPEG 编解码）：

| 尺寸 | 整图一次算 | 分批（256 行/批） |
|---|---|---|
| 24MP (4000×6000) | 4.0s，峰值 **2.0GB** | ≈2～3s，峰值 ~0.3GB |
| 45MP (5504×8256) | 7.9s，峰值 **3.8GB** | 8.5s，峰值 **0.53GB** |

**为什么要分批**：整图一次性线性化会为 45MP 开出 3.8GB 浮点临时数组——16GB 笔记本上
叠上 PIL 原图/输出和水印图层就有 OOM 风险。`apply_grade` 现按 256 行分块（`band_rows`），
逐像素运算分块与整图**逐位一致**（实测 maxdiff=0）；"自动黑点"改在 1/8 缩略图上
算一次复用（P0.5 是全局统计量，缩略图足够）。

默认模板是「原图」，不调色时这条链路完全不跑。8 秒/45MP 对批量仍偏慢，
下一步可做的优化是"每通道 8bit 输入 → 线性"的 256 级 LUT（输入本身就是 8bit，
LUT 无损），可省掉两次 pow。

## 八、测试

`tests/test_color_grade.py`：
- 强度 0 / 原图 = 像素恒等；
- 曝光↑ 平均亮度↑；对比↑ 标准差↑；饱和↑ 色度↑；黑白 → R=G=B；
- 输出恒在 [0,1]，黑点 auto 不额外削顶（贴顶比例 < 1%）；
- 模板读写往返、未知模板回退「原图」、用户段覆盖内置段；
- 端到端：`process_single_image` 套黑白后，边框颜色仍是设定值（调色没污染边框）。

## 九、风险与边界

- 8bit JPEG 推亮暗部可能有色阶（不额外做抖动，属"简单调色"的取舍）；
- 调色在缩放后执行 → 预览与导出走同一路径，观感一致；
- 模板名要与 ini 段名对应，名字里禁止 `]` 与换行（读入时清洗）。

## 十、实现与验证（2026-10-18）

按本设计落地，代码：

| 文件 | 内容 |
|---|---|
| `color_grade.py` | 颜色数学（线性光 8 参数）、模板解析/读写、`apply_grade` |
| `photo_watermark.py` | `_apply_grade()` 接入导出与预览；主界面「调色模板」面板；设置窗口「调色」页；CLI `--grade/--grade-strength`；`refresh_globals_from_ini` 同步 |
| `水印设置.ini` | `[基础设置] 调色模板/调色强度` + 5 个 `[调色模板:*]` 段（可手改，覆盖内置值） |
| `tests/test_color_grade.py` | 19 项：数学恒等/单调性/黑白/不削顶、auto 黑点削顶比例、模板读写往返/保留名/夹紧、导出链路（照片去色而白条边框不被染色） |

结果：

- 全库 **171 项测试全绿**（新增 19 + 原 152）；
- 主窗口、设置窗口构建冒烟通过（设置窗口在隐藏父窗口下构建，`saved=False`、
  没有任何配置写入——即打开设置不会偷偷保存）；
- 24MP 实测调色耗时约 4s/张（见第七节；已改分批，峰值内存 2.0GB → ~0.3GB）；
- 内置模板样张：`output/grade_templates_demo.jpg`。

与设计的差异（实现时定稿）：

1. 「黑点」增加 `auto` 取值（按照片线性 P0.5 自适应，上限 0.012），
   5 个内置模板里除「黑白」外都用 auto；
2. 设置窗口的调色页做成"模板编辑器"：下拉选模板 → 滑杆载入其参数 → 改动即时
   用于右侧预览（内部临时模板 `__编辑中__`，不写盘、不出现在下拉里）→
   「另存为模板」落盘；内置模板只可覆盖不可删除；
3. 自定义模板存 `用户设置.ini`，启动时与默认 ini 合并（同名覆盖）。
